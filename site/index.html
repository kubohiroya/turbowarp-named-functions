TurboWarp Named Functions

Define functions that take JSON arguments and return JSON results, then call them by name from any script.

Install

Load turbowarp-named-functions.js as a custom extension with Run without sandbox enabled.

Define and call

define function [add] description [Adds two numbers.] args schema [{"type":"object","properties":{"a":{"type":"number"},"b":{"type":"number"}},"required":["a","b"]}] export as [none]
return ((function argument [a]) + (function argument [b]))

when green flag clicked
say (call function [add] with [{"a":1,"b":2}])

NAME, DESCRIPTION, and the args schema must be typed directly into the hat. Arguments are checked against the schema before the function runs.

Start several calls, await them later

set [p1] to (start function [add] with [{"a":1,"b":2}])
set [p2] to (start function [add] with [{"a":3,"b":4}])
say (await all (join [[] (join (p1) (join [,] (join (p2) []])))))

Good to know

  • Each call takes at least one frame. Use custom blocks for tight loops and recursion.
  • A function that calls itself, directly or indirectly, fails with a reentrant-call error instead of waiting forever.
  • If something fails, check last function error.

define function [NAME] description [DESCRIPTION] args schema [SCHEMA] returns schema [RETURNS] export as [EXPORT]

Defines a named function. NAME, DESCRIPTION, and SCHEMA must be literal text. RETURNS is an optional JSON Schema for the return value; leave it blank to disable return validation.
